# StackMERN

Dépôt d'exercices pour la préparation au stage (1er septembre 2026), un dossier
par jour ou par projet.

- `jour-01-fetch-react/` — JavaScript asynchrone (fetch, async/await), petite
  app React/Vite. Voir `EXERCICE.md` à l'intérieur.
- `jour-02-js-avance/` — modules ES, méthodes de tableaux, `this`.
- `jour-03-nodejs/` — découverte de Node.js (npm, fs/promises).
- `jour-04-express/` — Express, routes et middlewares.
- `mini-projet-1-api/` — API "Gestionnaire de tâches", CRUD complet avec
  routes/contrôleurs séparés. En mémoire à la fin de la semaine 1, migrée
  vers MongoDB/Mongoose au Jour 8 (voir `EXERCICE-JOUR8.md`), tâches liées
  à un utilisateur et routes protégées par JWT au Jour 10 (voir
  `EXERCICE-JOUR10.md`).
- `jour-11-react-fondamentaux/` — Semaine 3 : composants, props, state
  (`useState`), rendu de listes. Voir `EXERCICE-JOUR11.md`.
- `jour-12-react-api/` — `useEffect`, connexion et récupération de
  données depuis `mini-projet-1-api` (JWT + CORS). Voir
  `EXERCICE-JOUR12.md`. CRUD complet (créer/modifier/supprimer) ajouté
  au Jour 13, voir `EXERCICE-JOUR13.md`.
- `jour-06-mongodb/` — MongoDB, Docker, MongoDB Compass (pas de code JS).
- `jour-07-mongoose/` — Mongoose : connexion, schémas, modèles, validation.
- `jour-09-auth/` — Authentification : hachage de mot de passe (bcrypt),
  tokens JWT, middleware de protection de routes. Voir `EXERCICE-JOUR9.md`.
